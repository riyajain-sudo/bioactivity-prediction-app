# Bioactivity Prediction App (Acetylcholinesterase)

This is a tutorial fork of [dataprofessor/bioactivity-prediction-app](https://github.com/dataprofessor/bioactivity-prediction-app), based on the Bioinformatics Project from Scratch tutorial. Upstream tutorial and PaDEL credit are preserved below; the local changes add input validation, isolated per-request descriptor workspaces, checked process timeouts, and ID-validated prediction mapping.

## Attribution

- Original app/tutorial by [Chanin Nantasenamat (Data Professor)](https://github.com/dataprofessor) — [tutorial video](https://youtu.be/htBIP17S-20).
- Molecular descriptors calculated with [PaDEL-Descriptor](http://www.yapcwsoft.com/dd/padeldescriptor/) ([paper](https://doi.org/10.1002/jcc.21707)); bundled third-party binaries and licenses remain under `PaDEL-Descriptor/`.

## Runtime prerequisites

- Python **3.10–3.12** and Java **8 or newer** available as `java` on `PATH`.
- Install app dependencies with `python -m pip install -r requirements.txt`.
- For notebook training, use `python -m pip install -r requirements-training.txt`; for local tests, also install `requirements-dev.txt`.
- Set `PADEL_MAX_HEAP` to a bounded Java heap such as `512M` or `1G` if needed. PaDEL runs with one worker and a 120-second timeout per request.

Dependency ranges are not a fully locked environment. The pickle format is coupled to scikit-learn versions: when changing Python/scikit-learn versions, regenerate `acetylcholinesterase_model.pkl` by running the included notebook and verify it before serving. The model file is generated locally and is not included in this source snapshot.

## Run the application

From this repository directory:

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

The model must first be generated by successfully running `bioactivity_prediction_app.ipynb`; the notebook writes `acetylcholinesterase_model.pkl` in the working directory. PaDEL JAR/config files are bundled here. If the generated model is absent, the app displays an actionable error rather than attempting prediction.

## Input format and limits

Upload a UTF-8 `.txt` file with exactly two whitespace-separated columns per non-comment row: **SMILES then a unique molecule ID**, for example:

```text
CCO ethanol_1
CCN ethylamine_1
```

Uploads are limited to 1,000,000 bytes and 100 molecules. The app creates request-specific scratch files and generated stable IDs; PaDEL output is joined back to molecule IDs and rejected if IDs are missing, duplicated, or unexpected. The app does not reuse output files between requests. Failed, timed-out, or malformed descriptor runs do not produce predictions. Model outputs are computational tutorial estimates, not clinical advice, dosing guidance, or evidence of efficacy.

## Offline tests

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q tests
```

The focused tests mock PaDEL and do not load a model, run Java, train, or contact external providers.
